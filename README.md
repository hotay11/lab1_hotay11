**Lab 1: Grade Evaluator & Archiver**

This project consists of two parts: the `grade-evaluator.py` Python script, which reads a grades CSV file and calculates a student's GPA, pass/fail status, and eligibility for resubmission; and the `organizer.sh` Bash script, which archives the grades CSV file and resets the workspace for the next set of grades.

Ensure that you have Python 3 installed and then from the project folder, run the grade evaluator with Python 3: `python3 grade-evaluator.py`. The script will ask you to enter the name of the CSV file to process, for example `grades.csv`. It assumes that the CSV will contain four columns: assignment, group, score, and weight with group being either Formative or Summative. The script verifies that all scores fall within the range 0-100, and that the sum of the scores for the Formative assignments is 60 and the sum of the scores for the Summative assignments is 40, to total 100. If those checks are passed then it will calculate the weighted grade and GPA with the formula: GPA = Total Grade / 100 x 5.0 It then prints the Formative and Summative category scores separately, as a student does not pass unless they achieve at least 50% in both categories, not just the overall score. Lastly, it mentions any formative assignments that earned less than 50 and those which earned the most, among those who failed, so that they can be resubmitted. The script prints a clear error message if the file is missing, empty or bad data.

To execute the organizer script, ensure that you are in the same folder as the `grades.csv`, and then execute the script using the bash command: `bash organizer.sh`. This script creates more than one file. If an `archive` folder doesn't already exist, it creates one. It then determines whether the file grades.csv exists, creates a timestamp and renames the existing grades.csv to a new name in the archive folder, e.g., grades_20251105-170000.csv. Then, it generates a new, blank `grades.csv` in the project folder, ready for you to enter the next set of grades. It also adds a new line to `organizer.log` every time it is run, with the time, the original file name and the archived file name, so that the log does not get rewritten, but it grows. To sum up, on the first run of the script, it will change up to four items: the archive folder itself, the timestamped copy inside, a new empty grades.csv, and a new line in organizer.log.

Usually, the grade evaluator is first run to check and review a set of grades and then the organizer script is run after that to archive the set of grades and reset the workspace for the next set.
